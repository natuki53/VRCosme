## 1. アプリ概要

VRCosme は、VRChat で撮ったスクリーンショットなどの写真を、明るさや色味を整えて SNS に投稿するためのレタッチアプリです。

主な特徴:

- スライダーで直感的に色味を調整できる
- AI を使って「人物だけ」「服だけ」のような特定の部分を選んで、その部分にだけ補正をかけられる
- Before / After を見比べながら調整できる
- 作業の途中で保存して、後で再開できる
- 日本語・英語・韓国語・中国語（簡体字／繁体字）の 5 言語に対応

---

## 2. 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| 必要ランタイム | なし（.NET 10 ランタイムは exe に同梱） |
| GPU | DirectML 対応 GPU があると AI 推論が高速化される（任意） |
| ネット接続 | 自動更新確認と AI モデルの初回ダウンロードに必要（オフラインでも本体機能は使える） |
| ディスク | アプリ本体 + AI モデル合計で約 300 MB 程度 |

---

## 3. 用語

| 用語 | 意味 |
|---|---|
| **補正** | 画像の明るさや色味を変える処理。明るさ・コントラストなど 13 種類ある。 |
| **プリセット** | 補正値の組み合わせを名前付きで用意したもの。「ふんわりポートレート」など。 |
| **マスク** | 補正をかけたい範囲を「ここだけ」と指定するための塗りつぶしデータ。 |
| **マスクレイヤー** | マスク 1 枚分のデータ。複数枚を重ねて、レイヤーごとに別々の補正をかけられる。 |
| **セッション** | 編集途中の状態（補正値、マスク、トリミング等）をまるごと保存したファイル（`.vrcproj`）。 |
| **Before / After** | 補正前 / 補正後。比較表示の切り替えで使う。 |
| **境界自然化** | マスクのフチをなめらかにして、補正の境目を目立たなくする処理。 |

## 4. 起動・終了

### 4.1 起動

- スタートメニューまたはデスクトップショートカットから起動
- 起動直後に、前回終了時の右パネル幅・テーマ・言語・各種設定が復元される
- 起動 1 〜 2 秒後にバックグラウンドで自動更新確認が走る（無効化可能）

### 4.2 終了

- ウィンドウ右上の × ボタン、メニュー「ファイル → 終了」、または `Alt + F4`
- **未保存の編集がある場合**、確認ダイアログが出る:
  - 「保存する」 → セッションを保存して終了
  - 「破棄する」 → 保存せず終了
  - 「キャンセル」 → 終了をやめる

## 5. 画像の読み込み

### 5.1 対応ファイル形式

入力: PNG / JPG / JPEG / BMP / TIFF / TIF / WEBP

### 5.2 読み込み方法

| 方法 | 操作 |
|---|---|
| ファイルダイアログ | メニュー「ファイル → 開く」または `Ctrl + O` |
| ドラッグ＆ドロップ | プレビューエリアに画像ファイルをドロップ |
| 最近使ったファイル | メニュー「ファイル → 最近使ったファイル」から選択（最大 10 件） |
| セッションから | `.vrcproj` を開くと、紐付いた元画像が読み込まれる |

### 5.3 読み込み中の挙動

- ステータスバーに「画像を読み込み中...」と表示
- 読み込み完了後、補正値はすべて初期値にリセットされる
- 未保存の編集があるときは、新しい画像を読み込む前に確認ダイアログが出る

### 5.4 サイズ制限

特に明示的な上限はないが、8000 × 8000 程度を超えるとメモリ消費が増えるため動作が重くなる場合がある。

## 6. 補正機能

### 6.1 基本補正

| 項目 | 範囲 | 既定値 |
|---|---|---|
| 明るさ | -100 〜 +100 | 0 |
| コントラスト | -100 〜 +100 | 0 |
| ガンマ | 0.2 〜 5.0 | 1.0 |
| 露出 | -5.0 〜 +5.0 | 0 |
| 彩度 | -100 〜 +100 | 0 |
| 色温度 | -100 〜 +100 | 0（マイナスで青、プラスで黄） |
| 色かぶり | -100 〜 +100 | 0（マイナスでマゼンタ、プラスで緑） |

### 6.2 詳細補正

| 項目 | 範囲 | 既定値 | 内容 |
|---|---|---|---|
| シャドウ | -100 〜 +100 | 0 | 暗部だけを持ち上げる／沈める |
| ハイライト | -100 〜 +100 | 0 | 明部だけを持ち上げる／沈める |
| 明瞭度 | -100 〜 +100 | 0 | 中間階調の輪郭を強調 |
| ぼかし | 0 〜 100 | 0 | ガウシアンぼかし |
| シャープ | 0 〜 100 | 0 | エッジを強調 |
| 周辺減光 | -100 〜 +100 | 0 | 画像の四隅を暗くする／明るくする |

### 6.3 操作方法

- スライダーをドラッグ → リアルタイムでプレビュー更新
- スライダー右の数値入力欄に直接値を入力 → Enter で確定
- 矢印キー（← →）で 1 ステップずつ変更
- 数値ラベルをダブルクリック → そのパラメータだけリセット
- 「リセット」ボタンで基本補正全部、詳細補正全部、または全パラメータをリセット

### 6.4 プリセット

あらかじめ次の 6 種類が用意されています。

| 名前 | イメージ |
|---|---|
| Soft Portrait | 明るく暖かいポートレート向け |
| Neon Night | 寒色系・コントラスト強めのネオン夜景風 |
| Sunset Film | 夕暮れフィルム調 |
| Cool Clear | 寒色系でくっきり |
| Matte Soft | マットで柔らかい仕上がり |
| Punchy Detail | コントラスト・ディテールを強調 |

操作:

- プリセット一覧から選択 → 「適用」ボタンで反映
- **強さ（0 〜 100 %）** を指定すると、現在の補正値とプリセットを補間してブレンド
- 「適用前に戻す」ボタンで、プリセット適用直前の状態に戻る

### 6.5 補正の処理順

順序は次のとおり固定です（実装側で決まっています）:

```
露出 → 色温度 → 明るさ → コントラスト → シャドウ／ハイライト
→ ガンマ → 周辺減光 → 彩度 → 明瞭度 → ぼかし → シャープ
```

## 7. トリミング

### 7.1 比率の選択肢

| ラベル | 用途 |
|---|---|
| None（なし） | トリミングを使わない |
| 1:1 | 正方形（Instagram 等） |
| 16:9 | 横長（YouTube サムネ等） |
| 9:16 | 縦長（TikTok 等） |
| 4:3 | 横長（一般的なカメラ） |
| 3:4 | 縦長（X / Twitter 投稿向け） |
| 3:1 | ヘッダー画像 |
| Free | 自由比率 |

### 7.2 操作

- 比率を選ぶと、画像中央に枠が表示される
- 四隅のハンドルをドラッグでサイズ変更
- 枠の中をドラッグで位置移動
- 「適用」ボタンを押すまでは書き出しに反映されない（プレビュー上の枠は表示）
- 一度適用した枠を再度変更すると「適用」がリセットされる

### 7.3 注意

- Free を選んだ場合は画像全体が初期サイズになる
- 回転や反転を行うと、枠は画像中央で初期化される

## 8. 回転・反転

| 操作 | ショートカット |
|---|---|
| 右に 90° 回転 | メニュー / ツールバー |
| 左に 90° 回転 | メニュー / ツールバー |
| 左右反転 | メニュー / ツールバー |
| 上下反転 | メニュー / ツールバー |

回転・反転を行うとマスクも同じ向きで動く（補正対象がズレない）。

## 9. 比較表示

3 つのモードを切り替えられます。

| モード | 内容 |
|---|---|
| After | 補正後だけを表示（既定） |
| Before | 補正前だけを表示 |
| Split | 縦の分割線を境に、左に補正前・右に補正後を表示 |

Split モードでは、画面上の分割線をドラッグして比率を変更できます。

## 10. マスク機能

### 10.1 マスクとは

「補正をかけたい場所」を白く塗り、それ以外を黒くした 1 枚の画像のようなものです。レイヤーごとに別々の補正値を設定できるので、たとえば次のようなことができます。

- 人物だけ明るく
- 背景だけぼかす
- 髪だけ色温度を下げる

### 10.2 マスクレイヤーの操作

| 操作 | 内容 |
|---|---|
| 追加 | 新しいマスクレイヤーを作る |
| 削除 | 選択中のマスクレイヤーを消す |
| 名前変更 | レイヤー名を変える（既定は「Mask 1」「Mask 2」…） |
| 表示 / 非表示 | マスクの効果をオン／オフ |
| 反転 | マスクの白黒を反転 |
| クリア | マスクを全部消して空にする |

### 10.3 マスクの生成手段

#### 手動ラッソ

- 「マスク編集」モードに入る
- プレビュー上をクリックしながらドラッグ → 軌跡を多角形として塗りつぶし

#### 色ベース選択

- 「色で選ぶ」モードに入る
- 似た色を選びたい場所をクリック
- 設定:
  - 色の許容差: 0 〜 80（既定 18）
  - 隙間を埋める半径: 0 〜 6（既定 1）
  - 4 近傍 / 8 近傍
  - アンチエイリアス: オン / オフ

#### AI 自動選択（SOD）

- 「AI 自動選択」ボタン → 画像全体から主役を自動検出
- モデル種別を「人物 / オブジェクト / 背景 / その他 / 軽量」から選択
- 初回利用時にモデルファイル（数十 MB）をダウンロード（同意ダイアログあり）

#### AI クリック選択

- 「AI クリック選択」モードに入る
- クリックした場所を起点に、AI が領域を切り出す

#### SAM クリック選択

- MobileSAM という別の AI を使う
- 細かい部位（服の一部、髪だけ等）の選択に向く
- 2 クリック目以降は高速（同じ画像のエンコード結果をキャッシュ）

### 10.4 既存マスクとの合成方法

「消しゴムモード」のオン／オフと、選択方法によって挙動が変わります。

| 状態 | 動作 |
|---|---|
| 通常モード + AI / 色選択 | 既存マスクに **追加**（OR）または **接続部分のみマージ** |
| 消しゴムモード | クリックや選択範囲を既存マスクから **削除** |
| マスククリア | レイヤーのマスクを全消去 |

### 10.5 マスク補正の設定

各マスクレイヤーは独自の補正値（13 種類）を持てます。「マスク補正」ダイアログから編集:

- スライダーで値を変えると、その場でプレビューが更新される
- 「境界を自然にする」をオンにすると、マスクのフチがなめらかにブレンドされる（ガタつき防止）
- 「OK」で確定、「キャンセル」で破棄

### 10.6 マスクと画像変換の追従

- 90° 回転、左右反転、上下反転を行うとマスクも同じ変換が適用される
- 画像の読み込み直後、トリミング適用後は、マスクサイズが自動的に画像サイズに合わせて作り直される

## 12. Undo / Redo

| 操作 | ショートカット |
|---|---|
| 元に戻す | `Ctrl + Z` |
| やり直し | `Ctrl + Y` または `Ctrl + Shift + Z` |

- 最大 20 回まで戻せる（超えた分は古いものから捨てられる）
- 戻せる対象: 補正値、トリミング、回転・反転、マスクの追加／削除／編集、マスクレイヤーの選択切替、マスク補正値の変更
- 「プリセット強さ」など一部のスライダーは Undo 履歴に積まれない

## 13. 書き出し

### 13.1 対応形式

| 形式 | 内容 |
|---|---|
| PNG | 可逆圧縮、画質の指定はなし |
| JPEG | 品質 1 〜 100（既定 90） |

### 13.2 書き出しの流れ

1. メニュー「ファイル → 書き出し」または `Ctrl + E`
2. 保存ダイアログでファイル名と場所を指定
3. 自動で `{元のファイル名}_edited.{拡張子}` が初期ファイル名になる
4. 「保存」 → 元画像のフル解像度で再計算 → 指定された形式で保存

### 13.3 書き出し内容

- 補正値（13 種類）が適用される
- マスクレイヤーの補正が、レイヤー順に適用される
- トリミングを適用済みの場合は、その範囲だけが書き出される
- 回転・反転も反映される

### 13.4 既定の保存先・形式

設定で次を変更できます:

- 既定の書き出し先フォルダ
- 既定の書き出し形式（PNG / JPEG）
- JPEG の既定品質

## 14. セッション保存

### 14.1 セッションとは

編集途中の状態を「`.vrcproj`」というファイルに保存できます。次回開けば、その続きから作業できます。

### 14.2 保存される内容

- 元画像へのパス（絶対パスと相対パスの両方）
- 13 個の補正値
- トリミングの状態（範囲、比率、適用済みかどうか）
- 回転・反転の状態
- 全マスクレイヤー（マスク本体 + レイヤー別補正 + 境界自然化フラグ）
- マスクの有効／無効、選択中のマスクレイヤー

### 14.3 操作

| 操作 | ショートカット |
|---|---|
| 上書き保存 | `Ctrl + S` |
| 名前を付けて保存 | `Ctrl + Shift + S` |
| 開く | `Ctrl + Shift + O` |

### 14.4 既定の保存先

`ドキュメント\VRCosme\Sessions\` を初期フォルダとして提示します。

### 14.5 元画像が見つからない時の挙動

1. 絶対パスでまず探す
2. なければ `.vrcproj` からの相対パスで探す
3. それでも見つからなければ、ユーザーに「元画像を選んでください」とダイアログを表示

## 15. 設定

メニュー「設定」または `Ctrl + ,` で設定ダイアログを開きます。タブで 4 領域に分かれています。

### 15.1 一般

- 言語: 日本語 / 英語 / 韓国語 / 中国語簡体字 / 中国語繁体字
  - 切り替えにはアプリ再起動が必要な部分がある旨を通知
- 三分割グリッド線の表示
- ルーラーの表示

### 15.2 書き出し

- 既定の書き出しフォルダ
- 既定の書き出し形式（PNG / JPEG）
- JPEG の既定品質（1 〜 100、既定 90）

### 15.3 AI（マスク自動選択）

- 推論デバイス: CPU / GPU（DirectML）
- 既定の AI モデル種別: 人物 / オブジェクト / 背景 / その他 / 軽量
- 既定の選択方式: SAM / Salient Object Detection
- マルチパス推論を有効にする（精度↑、時間↑）
- AI モデルの個別管理（インストール状況・削除・再ダウンロード）

### 15.4 更新

- 更新機能を有効にする
- 起動時に更新をチェック
- ベータ版（プレリリース）も取得する

## 18. 自動アップデート

仕様の詳細は `docs-internal/自動更新機能の設計書.md` を参照してください。要点:

- 起動時に GitHub Releases から最新版を確認
- 新しいバージョンがあれば通知ダイアログを表示
- 「ダウンロードして更新」「スキップ」「後で」「リリースページを開く」の 4 択
- スキップしたバージョンは、それより新しいものが出るまで再通知しない
- ベータ版（プレリリース）を含めるかは設定で切り替え可
- 失敗はサイレント（ログだけ残してアプリは普通に使える）

## 19. ログ

### 19.1 保存先

`%LocalAppData%\VRCosme\logs\VRCosme_{日付}.log`

### 19.2 ログレベル

| レベル | 用途 |
|---|---|
| INFO | 通常の動作記録（起動、画像読み込み、書き出し、設定変更など） |
| ERROR | 例外・処理失敗 |

### 19.3 保持期間

7 日。古いログは起動時に自動削除。

### 19.4 ログの書き出し

メニュー「ヘルプ → ログを書き出す」から、ログフォルダの全 .log を ZIP として保存できます。問い合わせの際に添付してもらうことを想定しています。

## 22. エラー時の挙動

基本方針は **「失敗してもアプリ自体は止めない」** です。

| 状況 | 挙動 |
|---|---|
| 画像読み込み失敗 | エラーダイアログを表示、ステータスバーをエラー表示に |
| 書き出し失敗 | エラーダイアログを表示、ファイルは作成されない |
| セッション保存失敗 | エラーダイアログを表示 |
| セッション読み込み失敗 | エラーダイアログを表示、現在の編集状態は維持される |
| プレビュー生成失敗 | ログだけ残し、画面は前回のプレビューを表示し続ける |
| 設定保存失敗 | 黙って無視（次回起動時に既定値に戻るだけ） |
| AI モデルのダウンロード失敗 | エラーダイアログを表示、リトライ可能 |
| GPU での AI 初期化失敗 | 自動的に CPU にフォールバック、警告ログを残す |
| 自動更新の通信失敗 | サイレント（ログのみ） |
| 想定外の例外 | エラーダイアログを表示、ログに記録、アプリは続行 |

## 23. 受け入れ基準

「これができていれば仕様を満たしている」と判断する観点です。

### 23.1 機能の受け入れ基準

- [ ] PNG / JPG / BMP / TIFF / WEBP の画像を開ける
- [ ] 13 種類の補正値をスライダーで調整でき、プレビューがリアルタイム更新される
- [ ] プリセットを適用し、強さで補間できる
- [ ] 8 種類の比率でトリミングでき、適用結果が書き出しに反映される
- [ ] 90° 回転と左右・上下反転ができ、マスクも追従する
- [ ] Before / After / Split の 3 モードで比較できる
- [ ] マスクレイヤーを複数作れ、レイヤーごとに別の補正をかけられる
- [ ] 手動ラッソ・色ベース・AI 自動・AI クリック・SAM クリックの 5 種類でマスクを作れる
- [ ] Undo / Redo が 20 回まで動作する
- [ ] PNG / JPEG（品質指定可）で書き出せる
- [ ] セッション（`.vrcproj`）を保存・読み込みできる
- [ ] 5 言語に切り替えられる
- [ ] ライト / ダーク / システム連動のテーマに切り替えられる

### 23.2 非機能の受け入れ基準

- [ ] スライダーをドラッグしてもアプリが固まらない
- [ ] 通信や設定の失敗で本体機能が止まらない
- [ ] 設定ファイルが壊れていても起動できる
- [ ] ログが自動で 7 日分管理される
- [ ] AI モデルは初回利用時にダウンロードされ、それ以降はオフラインで使える
- [ ] 画像処理はすべてローカルで完結する（外部にアップロードされない）
