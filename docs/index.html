FEATURES

主な機能

はじめてでも触りやすい、写真仕上げ向けの機能を集めました。

基本補正

明るさ、コントラスト、ガンマ、露出を素早く最適化。

詳細補正

シャドウ、ハイライト、明瞭度、シャープで質感を調整。

トリミング

アスペクト比固定や回転で、構図をテンポよく決定。

比較表示

補正前後・分割表示を切り替えて差分を明確化。

作業支援

Undo/Redo、ルーラー、グリッドで作業精度を安定。

書き出し

PNG/JPEGを選択して保存。JPEGは品質を細かく指定可能。
